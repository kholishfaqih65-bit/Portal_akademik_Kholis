# Portal Layanan Akademik
Website client satu halaman untuk studi kasus Portal Layanan Akademik.
## Teknologi
- HTML5
- CSS3
- Semantic HTML
- CSS Grid dan Flexbox
- Responsive Web Design
- HTML Form Validation
## Fitur
1. Header dan navigasi.
2. Bagian pengenalan portal.
3. Tiga kartu layanan akademik.
4. Form permohonan layanan.
5. Validasi input menggunakan HTML.
6. Tampilan responsif untuk mobile, tablet, dan desktop.
7. Navigasi keyboard dan indikator fokus.
8. Dukungan preferensi reduced motion.
## Struktur Folder
portal-layanan-akademik/
├── index.html
├── css/
│   └── styles.css
└── README.md
## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Buka file index.html melalui browser.
3. Jika tersedia, gunakan ekstensi Live Server untuk menjalankan website.
4. Uji tampilan melalui Chrome DevTools.
## Pengujian Responsif
Uji viewport berikut:
- Mobile: 360 px
- Tablet: 768 px
- Desktop: 1280 px
Periksa apakah halaman memiliki horizontal scroll,
teks tetap terbaca, dan formulir dapat digunakan.
## Catatan
Website ini merupakan prototipe front-end.
Form belum terhubung ke backend atau database.
Pengiriman form menggunakan perilaku GET bawaan browser.

Simpan screenshot hasil pengujian ke folder evidence
